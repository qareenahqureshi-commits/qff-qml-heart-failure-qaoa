# Quantum feature selection for heart-failure survival prediction

**KU QCI Qiskit Fall Fest 2026 — Quantum Machine Learning for Healthcare track**

> Which minimal panel of routine clinical measurements predicts death in heart-failure patients?
> We formulate panel selection as a relevance–redundancy QUBO, solve it with QAOA in Qiskit,
> and compare it — on identical data, splits, classifiers and metrics — against exhaustive search,
> simulated annealing, tabu search, and the classical feature-selection methods practitioners actually use.

Everything in this README is regenerated by `make all` (≈25 min on a laptop CPU; all results are
also committed under `results/`).

## 1. The healthcare problem

**Dataset.** UCI #519 *Heart Failure Clinical Records* (Ahmad et al. 2017; Chicco & Jurman 2020), CC BY 4.0.
299 patients from the Faisalabad Institute of Cardiology, 2015; 96 died during follow-up (32 %), 203 survived.
No missing values. Features (we follow Chicco & Jurman and exclude `time`, the follow-up length, because it is
not known at admission):

| feature | type | | feature | type |
|---|---|---|---|---|
| age | years | | platelets | kiloplatelets/mL |
| anaemia | 0/1 | | serum_creatinine | mg/dL |
| creatinine_phosphokinase | mcg/L | | serum_sodium | mEq/L |
| diabetes | 0/1 | | sex | 0/1 |
| ejection_fraction | % | | smoking | 0/1 |
| high_blood_pressure | 0/1 | | **DEATH_EVENT** (target) | 0/1 |

**Why panel selection.** Chicco & Jurman's central finding is that a two-feature panel (serum creatinine +
ejection fraction) predicts survival *better* than all features — fewer measurements, cheaper triage, less
over-fitting. They obtained it by ranking features with classifier importances. The question we ask is whether a
*principled, joint* relevance–redundancy criterion can recover or improve that panel, and whether a quantum
optimiser can solve that criterion.

**Intended outcome.** A ranked set of minimal panels (k = 2, 3, 4) with honest confidence intervals, and a
quantum solver pipeline that scales to larger panels than brute force allows.

**Metric.** Matthews correlation coefficient (MCC) is primary, because the classes are imbalanced; accuracy,
F1, sensitivity, specificity, PR-AUC and ROC-AUC are reported alongside.

**Classical feature-selection baselines** (`src/solvers.py`), all evaluated under the same protocol:

* **Exhaustive search** of all 2¹¹ = 2048 subsets of the QUBO objective → the provable optimum (ground truth
  for every solver below).
* **Simulated annealing** and **tabu search** on the *same* QUBO — the fair classical heuristics
  recommended by the quantum-optimisation benchmarking literature (arXiv 2405.07624), tuned with the same care
  as QAOA (geometric schedule, 200 sweeps, 50 restarts).
* **Random sampling** (2000 samples) — lower bound.
* **Greedy mRMR** on the same MI relevance/redundancy quantities — the greedy counterpart of the QUBO.
* **Lasso** (L1-logistic path, top-k by |coef|), **RFE** (random forest), **RF impurity importance** —
  what practitioners use.

## 3. The quantum contribution

### 3.1 Formulation — feature selection as a QUBO

Following Mücke, Heese, Müller, Wolter & Piatkowski (2023):

```
minimise  Q(x, α) = −α Σᵢ Iᵢ xᵢ  +  (1−α) Σ_{i≠j} R_ij xᵢ xⱼ ,   x ∈ {0,1}¹¹
```

* **MI variant**: `Iᵢ = MI(featureᵢ; label)` (relevance), `R_ij = MI(featureᵢ; featureⱼ)` (redundancy),
  continuous features discretised into 20 quantile bins (as in the paper).
* **Fisher variant** (arXiv 2609.30256): `Iᵢ` = Fisher score, `R_ij = |cov|`, both min-max normalised —
  no binning, better-conditioned coefficients.
* **Number of features k** is *not* enforced with a penalty `λ(Σxᵢ − k)²` — Mücke et al. show λ is
  ill-conditioned. Instead their Proposition 1 guarantees an α whose minimiser has exactly k ones; we find it by
  binary search (`src/qubo.py::alpha_for_k`). Resulting α: MI 0.875 / 0.969 / 0.984, Fisher 0.500 / 0.750 / 0.875 for k = 2 / 3 / 4.

The QUBO is mapped to an Ising Hamiltonian `Σ hᵢ Zᵢ + Σ J_ij Zᵢ Zⱼ` via `x = (1−Z)/2`
(`src/qaoa.py::qubo_to_ising`); the mapping is verified exact on all 2048 basis states (max error 9e-16).

### 3.2 Solver — QAOA in Qiskit

`QAOAAnsatz` on the cost Hamiltonian, one qubit per feature (11 qubits), transpiled to `AerSimulator`,
objective estimated from **shots** with `SamplerV2` (same noisy-objective regime as hardware), optimised with
**COBYLA** (≤150 evaluations, 2000 shots each), random initial angles, **10 independent seeds** per
configuration, depth **p ∈ {1, 2, 3}**. Settings mirror Turati et al. (2022, arXiv 2211.02861) and
arXiv 2609.30256; both report high run-to-run variance, so every number below is mean ± std over seeds.

### 3.3 Why quantum here, and which limitation it addresses

* **Greedy ≠ joint.** mRMR adds one feature at a time and cannot revisit choices. On this dataset greedy mRMR on
  the identical MI matrices selects `{anaemia, high_blood_pressure, serum_creatinine}` — binary features with
  near-zero redundancy but also near-zero relevance — giving RF MCC 0.225. The joint optimum of the same
  objective gives 0.430. The QUBO fixes the *optimiser*, not the criterion.
* **Exhaustive search does not scale.** 2ⁿ is fine at n = 11 (which is exactly why we can validate every solver
  against the true optimum here) and impossible at the n ≈ 50–500 of real metabolomic / genomic panels, where
  the same QUBO needs n qubits and the circuit grows polynomially.
* **What we do not claim.** No quantum advantage at n = 11: simulated annealing and tabu solve this instance to
  optimality every time, in 0.3 s. See §5.

## 4. Fair evaluation

### 4.1 Optimiser quality (all solvers, same QUBO, same ground truth)

Metrics (`src/solvers.py::optimiser_metrics`): **approximation ratio** AR = (E_max − E)/(E_max − E_opt)

the exhaustive optimum; **feasibility** = fraction with exactly k features; **found** = fraction of seeds whose
best sample *is* the optimum; **top-5** = fraction of seeds where the optimum is among the 5 lowest-energy
*distinct* sampled subsets (the practical selector protocol: sample, then classically evaluate the top few).

Observations:
1. **QAOA's best-of-2000-shots sample is the exhaustive optimum in essentially every seed** (58/60
   configuration × seed runs at p = 1, 59/60 at p = 2, 60/60 at p = 3). As a *subset selector* it is reliable at this size.
2. **Mean sample quality is far below SA/tabu**, especially on the MI QUBO at k = 3, 4 (AR ≈ 0.6–0.7). The MI
   objective has four features with MI ≈ 0 (diabetes, sex, smoking, anaemia) whose flips cost almost nothing, so
   the landscape is near-degenerate (6 bitstrings within 1 % of the optimum at k = 2 and k = 4).
3. **The Fisher/covariance formulation is markedly better-conditioned for QAOA** — AR_mean 0.90 at every k, and
   P(opt) per shot up to 17 % versus 0.2 % for MI. Reformulating the QUBO mattered more than adding depth.
4. **Depth helps modestly and monotonically** (p = 1 → 3 adds 0.01–0.07 AR), consistent with Turati et al.

### 4.3 Quantum resource / efficiency metrics

The QUBO is dense (every feature pair has non-zero redundancy), so each QAOA layer needs all 55 ZZ
interactions. Left: logical circuit, all-to-all `{rz, sx, x, cx}`. Right: the same circuit routed onto the
heavy-hex coupling map of a 133-qubit IBM Heron (`fake_torino`, optimization_level 3) — SWAP overhead roughly
doubles the two-qubit gate count.

| p | parameters | logical depth | logical CX | logical gates | routed depth | routed 2q gates | routed gates | shots / eval | COBYLA evals |
|---|---|---|---|---|---|---|---|---|---|
| 1 | 2 | 67 | 110 | 265 | 406 | 232 | 1029 | 2000 | ≤150 |
| 2 | 4 | 106 | 220 | 496 | 709 | 452 | 2016 | 2000 | ≤150 |
| 3 | 6 | 145 | 330 | 727 | 1079 | 676 | 2914 | 2000 | ≤150 |

11 logical qubits in every case. Classical comparators: exhaustive 2048 evaluations (0.03 s); SA 50 × 200 × 11

and §4.4 measures it.

Observations:
1. **Noise costs 0.03–0.17 in mean approximation ratio and 2–10× in per-shot optimum probability.**
2. **Depth now hurts.** Ideal AR rises with p; on the device it falls monotonically (p = 3 adds 444 routed
   two-qubit gates). This is the NISQ crossover the benchmarking literature warns about; **p = 1 is the depth to
   run on real hardware** for this instance.
3. **The selector protocol survives.** In all 93 noisy runs the exhaustive optimum is still the lowest-energy
   sample *and* within the top-5 distinct subsets. A user who samples once and classically checks five
   candidate panels gets the optimal panel every time — that is the realistic way to use QAOA here.
4. Optimising directly under noise (protocol B) reaches the same quality as parameter transfer at 10× the cost.

### 4.5 Choosing k without looking at the test set

`scripts/06_select_k.py`. Reporting the k = 3 panel as "best" after seeing §4.2 would be test leakage. So, for
each of the same 100 outer splits, we rebuild the Fisher QUBO on the **training 80 % only**, take its optimum
for k ∈ {2,3,4} (what QAOA finds in 10/10 seeds at p ≥ 2), choose k by inner 5-fold CV MCC, and evaluate once
on the held-out 20 %.

| | |
|---|---|
| k chosen | **3 in 55 / 100** splits, 2 in 23, 4 in 22 |
| panel chosen | `age + ejection_fraction + serum_creatinine` **51 / 100**; `ejection_fraction + serum_creatinine` 23; `… + serum_sodium` 14; six other panels ≤4 each |
| k = 3 training-set optimum equals the full-data panel | 83 / 100 splits |
| leakage-free test performance (RF, mean of 100) | **MCC 0.391 ± 0.021**, F1 0.571, acc 0.739, TPR 0.554, TNR 0.825, PR-AUC 0.629, ROC-AUC 0.782 |

![nested](results/figures/nested_k_selection.png)

The honest number for "what would a practitioner get from this pipeline" is therefore 0.391, not 0.430 — still
above the all-feature model (0.365) and level with the published hand-picked panel (0.398). The gap between
0.391 and 0.430 is the price of selecting k on 239 training patients instead of 299.

## 5. Trade-offs, limitations, and what this does and does not show

* **No quantum advantage is claimed.** At n = 11, exhaustive search is trivial and SA/tabu are perfect. The
  value shown is (i) a QUBO criterion whose *joint* optimum is a better clinical panel than greedy selection
  of the same criterion and than the published panel, and (ii) a QAOA pipeline that reliably recovers that
  optimum as its best sample, validated against ground truth — the prerequisite for using it where ground truth
  is unavailable.
* **Mean sample quality vs best sample.** QAOA's strength here is "contains the optimum among 2000 shots", not
  "most shots are optimal". If a downstream user can afford to evaluate the top-m sampled subsets classically,
  QAOA is a usable selector; if they need a single optimal shot, it is not, at these depths.
* **Formulation sensitivity.** The MI QUBO's unnormalised, small coefficients produce a near-degenerate
  landscape; the Fisher/covariance QUBO is the one to take forward. Mutual information also depends on the
  binning (B = 20).
* **Dataset size.** 299 patients and 96 events; confidence intervals of ±0.02 MCC are honest but the ranking of
  panels within ~0.03 of each other should not be over-read. We report paired tests on shared splits to make the
  headline comparisons defensible.
* **Simulated noise, not hardware.** §4.4 uses IBM's published calibration model of a Heron device, which
  captures gate/readout error and T₁/T₂ but not drift, crosstalk or non-Markovian effects. A real p = 1 run on
  the IBM free tier is the obvious next step; the code path is a one-argument change (`noisy="<backend>"`).
* **k on small data.** Nested selection (§4.5) picks the k = 3 panel only ~half the time; with 239 training
  patients the k = 2/3/4 optima are often within noise of each other.
* **Hyper-parameters.** Classifier settings are fixed a priori (Chicco & Jurman defaults); α is set by the
  k-binary search, not tuned on outcomes; COBYLA budget and shot count follow the cited papers rather than a
  sweep.
